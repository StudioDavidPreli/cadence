Remove layout from wrapper. Set exit={{ opacity:0, transition:{ duration: dur.base } }}. Timer consolidation

Decision: onLayoutAnimationComplete.
Fires on the card's actual FLIP completion — not a race against clock drift. Check isExpanded captured in closure. React 18 batches all setState calls in same microtask.

M5 race (isStable / dims gap)

Decision: batch in same callback.
Call setIsStable(true) and setExpandedDimensions({...}) inside the same onLayoutAnimationComplete. React 18 automatic batching merges them into one render — no one-frame window.

Mobile clipping (β)

Decision: defer. Add overflow-y:auto.
At @container ≤600px, stacked content may exceed 2-row card height. Scroll is correct: clipping silently hides content, natural height breaks deterministic FLIP. Add overflow-y:auto to expandedWrapper in the @container rule when implementing mobile.
